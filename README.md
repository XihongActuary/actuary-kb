# 精算师说保险 · 知识库

一个精算师写的保险科普知识库：19 页正文（序言 + 16 章 + 全书结语），从大数法则讲到买对保险，每章配手绘风 SVG 插画，全部为官方口径，不推销、只讲逻辑。

**在线阅读**：<https://xihongactuary.github.io/actuary-kb/>

## 目录

- **序言** — 为什么你需要懂一点儿精算
- **基础篇（1～5 章）** — 大数法则、生命表、利息与折现、风险分级与定价、可保风险
- **进阶篇（6～10 章）** — 保单价格拆解、准备金与投资、自然保费 vs 均衡保费、利差损与资产负债管理、产品停售的真相
- **应用篇（11～16 章）** — 买重疾险、百万医疗险、年金险 IRR、演示利率、保险公司安全网、行业未来（上/下）
- **全书结语** — 精算思维陪你走完
- **延伸资源** — 官方权威链接（金融监管总局、保险业协会、精算师协会等）
